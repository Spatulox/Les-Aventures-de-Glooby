# Les-Aventures-de-Glooby

The goal of this school project is to only uses AI to generate the game...



System requirements

Windows (x86_64)

    Windows 10 (1909+) or 11
    Direct3D 12 GPU, feature level 12_0
    Nothing else to install (.NET runtime is bundled)

Linux (x86_64 / arm64)

    glibc 2.28+, kernel 5.15+ (Ubuntu 22.04, Debian 12, Fedora 36 or newer)
    GPU + driver with Vulkan 1.0 support
    X11 or Wayland display server, ALSA or PulseAudio
    Nothing else to install (.NET runtime is bundled)

Installation

Unzip and run the executable. Keep all 3 items together
(executable + .pck + data_* folder) — they cannot be separated
On Linux, run chmod +x GloobyAventures.x86_64 if needed
Note

AI-generated dialogue downloads Ollama and its model on first launch
The game is fully playable offline (can be disabled in Settings)
